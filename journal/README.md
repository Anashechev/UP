# 🎓 Журнал студентов

Веб-приложение для управления студентами, группами и предметами, разработанное на Spring Boot.

## 📋 Описание

Система предоставляет полный функционал для управления образовательными данными:
- **Студенты**: управление личными данными студентов
- **Группы**: управление учебными группами
- **Предметы**: управление учебными предметами

## 🚀 Запуск приложения

1. Убедитесь, что у вас установлена Java 17 или выше
2. Клонируйте репозиторий
3. Перейдите в директорию проекта
4. Запустите приложение:
   ```bash
   ./mvnw spring-boot:run
   ```
   или
   ```bash
   mvn spring-boot:run
   ```
5. Откройте браузер и перейдите по адресу: `http://localhost:8080`

## 📱 Использование

### Главная страница
- Перейдите на `http://localhost:8080` для доступа к главной странице
- Выберите нужный раздел: Студенты, Группы или Предметы

### Студенты
- **Добавление**: заполните форму и нажмите "Добавить студента"
- **Поиск**: используйте поле поиска для поиска по имени
- **Фильтрация**: используйте форму фильтрации для поиска по возрасту и email
- **Редактирование**: измените данные в форме и нажмите "Обновить"
- **Удаление**: 
  - "Скрыть" - логическое удаление (запись скрывается)
  - "Удалить навсегда" - физическое удаление
- **Множественное удаление**: выберите записи чекбоксами и используйте кнопки массового удаления
- **Пагинация**: используйте навигацию по страницам внизу списка

### Группы
- Управление учебными группами
- Добавление, редактирование, удаление групп
- Поиск по названию группы

### Предметы
- Управление учебными предметами
- Добавление, редактирование, удаление предметов
- Поиск по названию или коду предмета
- Указание количества кредитов

## 🔧 Особенности реализации

- **In-Memory хранение**: данные хранятся в памяти приложения (исчезают при перезапуске)
- **Логическое удаление**: удаленные записи помечаются флагом `isDeleted`
- **Валидация**: проверка обязательных полей и корректности данных
- **Responsive дизайн**: адаптивный интерфейс для различных устройств
- **JavaScript**: интерактивные элементы для множественного выбора

## 📊 Модели данных

### StudentModel
- ID, имя, фамилия, отчество, дополнительное имя
- Email, телефон, возраст
- Время создания и обновления
- Флаг удаления

### GroupModel
- ID, название, описание
- Время создания и обновления
- Флаг удаления

### SubjectModel
- ID, название, код, количество кредитов, описание
- Время создания и обновления
- Флаг удаления

## 📝 Примечания

- Приложение использует in-memory хранение данных
- При перезапуске приложения все данные сбрасываются
- Для production использования рекомендуется подключить базу данных
- Все операции логируются в консоль Spring Boot
